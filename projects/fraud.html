Sequence-Based Transaction Fraud Detection

Three deep sequence architectures benchmarked against gradient boosting under an explicit cost model, with the sequence models' advantage isolated to robustness under drift specifically.

View on GitHub →

01The problem

Real-time transaction fraud detection needs to catch adaptive fraud patterns — card testing, account takeover, merchant compromise — while staying inside a strict latency budget and remaining honest about whether the added complexity of deep sequence models is actually earning its cost over a much simpler baseline.

02The result

Headline number

Sequence models cut expected cost per transaction by 27% (0.0665 vs 0.0906) under an explicit cost model — but the margin came entirely from robustness to injected adversarial drift. Pre-drift, gradient boosting was marginally ahead (0.956 vs 0.950 PR-AUC). Served via ONNX Runtime at 5.1ms p99 end-to-end latency against a 50ms budget.

03Architecture

GRU / TCN / causal Transformer (<115k params each) vs LightGBM baseline → focal loss / weighted sampling → temperature + isotonic calibration → ONNX export → FastAPI serving

04The hardest decision

Why the honest pre-drift number matters more than the headline 27%

Reporting only the post-drift 27% cost reduction would have been a true but misleading framing — it implies the sequence models are simply better. The pre-drift comparison (0.956 vs 0.950 PR-AUC, effectively a tie) is what actually locates why they win: not raw predictive power, but robustness when the fraud pattern itself shifts. That distinction changes the real recommendation — it's an argument for the added complexity specifically in a non-stationary threat environment, not a blanket 'deep learning wins' claim.

05What the results actually showed

Measured, not assumed

Focal loss and weighted sampling, the two standard fixes for class imbalance, failed in different ways rather than both simply helping: focal loss degraded probability calibration (ECE 0.0063) while weighted sampling instead cost ranking quality (−0.042 PR-AUC). Neither fix was free, and knowing which one costs what let calibration be corrected surgically afterward — temperature scaling and isotonic regression brought ECE down to 0.0005 — rather than accepting whichever trade-off the first technique happened to introduce.

06What's next

Test against a wider set of injected drift patterns to check whether the robustness advantage generalizes beyond the specific drift mechanism used in evaluation.
